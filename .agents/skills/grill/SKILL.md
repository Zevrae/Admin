# GRILL Code Cleaning Skill

## Objective
Improve code quality, readability, maintainability,
security, and performance.

## Instructions

1. Inspect the relevant code and dependencies.
2. Identify unused imports, variables, and functions.
3. Remove redundant code and unnecessary duplication.
4. Improve naming and formatting.
5. Simplify complex conditions and functions.
6. Identify potential bugs and security issues.
7. Optimize inefficient code when safe.
8. Preserve existing functionality and public APIs.
9. Run available linting, formatting, and tests.
10. Report changes and any remaining issues.

## Safety Rules

- Do not delete required functionality.
- Do not change business logic without approval.
- Do not modify secrets or environment files.
- Do not install packages without approval.
- Do not modify unrelated files.
- Review changes before applying destructive actions.

## Output

Provide:
- Files cleaned
- Problems detected
- Improvements made
- Tests performed
- Remaining warnings
